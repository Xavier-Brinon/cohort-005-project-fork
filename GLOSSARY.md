# Billing & Learner Access

How a learner buys a course, gets access to it, and gets their money back. One
time-based concept per term; the money-back story is the focus.

## Language

**Purchase**:
A one-time buy of a single course that grants access for as long as it is not
cancelled.
_Avoid_: subscription, order, transaction, checkout

**Cancellation**:
A learner's request to stop a purchase, allowed only within the cancellation
window. Accepting it ends the learner's access and opens a Refund.
_Avoid_: reversal, opt-out, unsubscribe, terminate

**Cancellation window**:
The limited period after a Purchase during which it can still be Cancelled.
_Avoid_: refund window, grace period

**Refund**:
The return of money for a Purchase; a pending outcome a request can be approved
or declined. Cancellation is its only cause today, but the word is an umbrella so
future causes (an aging course, a returned team seat) can be named without
renaming it.
_Avoid_: chargeback, reversal

## Notes on deliberate word choices

- "Refund" is an **outcome**, never the action. The action is "cancel." A
  learner cancels; the system refunds.
- "Chargeback" is deliberately rejected: a chargeback is a card issuer forcing
  money back, which is not what a learner-initiated request is.
